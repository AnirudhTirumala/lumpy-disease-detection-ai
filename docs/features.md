\# Lumpy Disease Detection AI



\## Project Overview



An AI-powered mobile and web platform for detecting Lumpy Skin Disease (LSD) in cattle using image analysis and machine learning.



\---



\## Farmer Features



\- Register account

\- Login securely

\- Upload cattle images

\- View AI prediction results

\- View confidence score

\- View annotated disease image

\- View generated reports

\- Track previous submissions

\- Manage profile



\---
